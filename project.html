Featured Project — Capstone Project

Mobile Citizen Reporting System

Capstone project: a mobile citizen reporting system built for Bongao, Tawi-Tawi.

  • Stack: FastAPI, PostgreSQL, React
  • Methodology: Agile/Iterative SDLC
  • Architecture: Three-tier design with cross-cutting concerns for security, data privacy, and deployment

Key Highlights

  • Standardized system roles (Main Administrator, Department Representative) across the proposal
  • Usability target validated against a System Usability Scale (SUS) benchmark of ≥68
  • Rebuilt system flowcharts from user-flow to system-process style using Graphviz, with matching narrative revisions
  • Produced a full 20-slide, university-branded defense deck with native diagrams, embedded UI mockups, and a Taglish defense script
  • Evolved from an earlier web-app prototype ("Citizen Reporting System") through multiple chapter revisions
